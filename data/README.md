# Dataset Attribution & Licensing

## Source
The raw behavioral data in `data/raw/` originates from the open-access dataset published alongside:

> **Dezfouli, A., Griffiths, K., Ramos, F., Dayan, P., & Balleine, B. W. (2019).** *Models that learn how humans learn: The case of decision-making and its disorders.* PLOS Computational Biology, 15(6), e1006903. https://doi.org

* **Original Repository:** [Figshare Dataset (DOI: 10.6084/m9.figshare.8257259)](https://figshare.com)

## Modifications
* `data/raw/`: Unmodified original files as downloaded from Figshare.
* `data/processed/`: (Generated via `src/dataset.py`) Contains cleaned sequences and train/test splits formatted for PyTorch.
